# Deep Ensembles for Uncertainty Quantification

## Running Experiments

### CNN Experiments
Run `main_cnn.py` in `notebooks/CNN_Ensemble_Calibration/`

### LLM Experiments
Run `main_iclr.py` in `notebooks/Ensembling_Finetuned_LLMs/`

### JUCAL
The JUCAL implementation is located in `src/`

## Data

### CNN Data
The CNN prediction data is not included in this repository. You can generate it yourself or obtain it from open-source sources.
